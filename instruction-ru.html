Инструкция

Как подключиться к Guard VPN

1
Скачай приложение
Выбери подходящее приложение для своего устройства:
📱 Happ (Android) 🍏 Happ (iOS) 📱 v2rayNG (Android) 💻 Hiddify (Win/Mac/Linux)
2
Получи ссылку
Вернись на главный экран и нажми кнопку «Получить конфиг». Скопируй полученную ссылку.
💡 Пример ссылки: https://ваш-сервер/sub/abc123xyz
3
Добавь подписку
Для Happ:
Открой приложение → нажми «Подписка» → «Добавить подписку» → вставь ссылку → «Добавить»
Для v2rayNG:
Открой приложение → нажми «+» → «Добавить подписку» → вставь ссылку → «ОК»
4
Подключись
Выбери сервер из списка и нажми на кнопку подключения. После подключения статус изменится на «Защищено».
⚠️ Не работает?
• Попробуй сменить сервер
• Обнови ссылку — нажми «Получить конфиг» ещё раз
• Переустанови приложение
• Свяжись с поддержкой
